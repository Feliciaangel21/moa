## 서비스 소개

여행지는 정했지만 여러 명의 취향과 조건이 다를 때, 여행 계획은 쉽게 길고 피곤한 단체 채팅이 됩니다. 모아에서는 각 참여자가 약 7분 동안 자신의 조건과 취향만 입력합니다. 이후 개인 AI 대리인들이 대신 회의하고, 분야별 심판이 실제 후보와 제약을 검토해 최종 계획을 조율합니다.

모아가 중요하게 생각하는 가치는 세 가지입니다.

- **최소 참여:** 사용자는 자신의 절대 조건과 취향만 알려주면 됩니다.
- **AI 대리:** 개인 대리인이 사용자의 입장을 바탕으로 대신 의견을 내고 협상합니다.
- **납득 가능한 결과:** 일정뿐 아니라 결정 이유, 만족도, 양보 기록, 소수 의견까지 확인할 수 있습니다.

## 핵심 경험

### 1. 목적지가 정해진 여행 방

호스트가 목적지, 날짜, 인원, 예산, 취향 입력 마감일을 정하고 초대 링크를 공유합니다. 목적지는 회의 대상이 아니며, 이후 설문과 후보 데이터의 기준이 됩니다.

### 2. 4단계 취향 입력

- 절대 양보할 수 없는 예산·식이·접근성·생활 조건
- 12개의 여행 스타일 축
- 오사카 전용 활동 20개의 1–10점 선호도
- 꼭 하고 싶은 것과 피하고 싶은 것

### 3. `MY AGENT`

입력한 내용을 바탕으로 개인 AI 대리인의 여행 스타일, 예산, 절대 조건, 우선순위, 협상 방식을 보여줍니다. 사용자는 회의에 보내기 전에 반드시 내용을 확인합니다.

### 4. 비동기 AI 여행 회의

모든 참여자의 대리인이 준비되면 7개 라운드의 회의가 백그라운드에서 진행됩니다. 사용자는 앱을 계속 켜두거나 회의에 직접 참여할 필요가 없습니다.

### 5. 만족도부터 보여주는 결과

최종 결과는 지도보다 먼저 평균·최저 만족도와 개인별 반영 정도를 보여줍니다. 이후 일정, 예약 항목, 예산, 공평성, 소수 의견, 미해결 사항, Plan B를 확인할 수 있습니다.

### 6. AI 회의 다시보기

완료된 회의를 라운드별로 재생하며 다음 기록을 구분해서 보여줍니다.

- 개인 대리인의 주장
- 참여자 사이의 의견 충돌
- 분야별 심판의 팩트체크
- 라운드 판결
- Chief 재심

### 7. 필요한 부분만 재논의

전체 여행을 다시 만들지 않고 숙소, 식사, 액티비티, 교통 중 아쉬운 카테고리만 다시 논의할 수 있습니다.

## 데모 흐름

```text
랜딩
→ 여행지 선택
→ 여행 방 만들기
→ 초대 링크 공유
→ 멤버 준비 상태
→ 4단계 취향 입력
→ 개인 AI 대리인 확인
→ 제출하고 앱 나가기
→ 7라운드 AI 회의
→ 만족도 중심 최종 결과
→ 회의 다시보기
→ 카테고리별 재논의
```

현재 버전은 오사카 3박 4일, 6인 그룹을 기준으로 만든 프론트엔드 프로토타입입니다. 참여자 취향과 충돌, 판결, 일정, 만족도 데이터는 전체 화면에서 하나의 일관된 이야기로 연결됩니다.

## 주요 화면 바로 열기

발표와 QA를 위해 URL 쿼리로 핵심 화면에 바로 접근할 수 있습니다.

| 화면 | 주소 |
| --- | --- |
| 랜딩 | `/?stage=landing` |
| 여행 방 생성 완료 | `/?stage=invite` |
| 그룹 준비 상태 | `/?stage=lobby` |
| 절대 조건 설문 | `/?stage=hard` |
| 개인 AI 대리인 | `/?stage=persona` |
| 회의 진행 상태 | `/?stage=running` |
| 최종 결과 | `/?stage=result` |
| 상세 일정과 지도 | `/?stage=result&tab=itinerary` |
| 공평성 설명 | `/?stage=result&tab=fairness` |
| 회의 다시보기 | `/?stage=replay` |

## 기술 스택

- React 19
- TypeScript 5.8
- Vite 7
- Framer Motion
- Phosphor Icons
- Tailwind CSS / PostCSS
- Vercel

## 로컬 실행

Node.js 20 이상을 권장합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 열면 됩니다.

## 품질 검사

```bash
npm run lint
npm run build
```

프로덕션 빌드를 로컬에서 확인하려면 다음 명령을 실행합니다.

```bash
npm run preview
```

## 현재 구현 범위

이 저장소는 대회 시연을 위한 고충실도 프론트엔드 프로토타입입니다.

- 참여자 진행률, 대리인 생성, 회의 라운드, 팩트체크, 판결과 재논의는 현실적인 목 데이터로 시뮬레이션됩니다.
- 링크 복사, 카카오톡 공유, 예약 페이지 연결은 프로토타입 상호작용입니다.
- 실제 사용자 인증, 알림, 예약 API, 멀티 에이전트 백엔드 연결은 추후 연동 대상입니다.
- 외부 여행 사진은 Unsplash URL을 사용합니다.

## 디자인 원칙

- 한국어를 주요 언어로 사용하고 영어는 작은 브랜드 레이블에만 제한합니다.
- 여행 서비스의 따뜻함을 먼저 보여주고 AI는 조용히 뒤에서 작동하도록 표현합니다.
- 평균 만족도만 높이는 대신 최저 만족도, 양보 기록, 반대 의견과 불확실성을 함께 공개합니다.
- 모바일 설문과 일정, 회의 다시보기는 한 손 사용을 고려합니다.

---

모아는 단순히 일정을 생성하는 서비스가 아니라, **여러 사람의 AI 대리인이 대신 협상하고 그 결정 과정을 투명하게 설명하는 여행 중재 경험**을 목표로 합니다.
